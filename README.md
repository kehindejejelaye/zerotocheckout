# Zero to Checkout: The AI Architect Masterclass (2026)

**From Idea to Checkout in 48 Hours.**

Zero to Checkout is a premium masterclass designed to navigate the "AI Correction." We transform manual laborers—founders, developers, and students—into **AI Architects** capable of building production-grade, commercial systems that validate ideas through live payment integration.

## 🚀 The Vision
The world in 2026 doesn't reward "lines of code"; it rewards **Commercial Systems that Work.** This project is the digital home of the masterclass, designed to communicate urgency, technical rigor, and the path from a non-existent idea (Zero) to a live payment-collecting system (Checkout).

## 🛠️ Tech Stack
- **Frontend:** HTML5, Bootstrap 5 (Responsive Layout)
- **Styling:** Custom Vanilla CSS (Glassmorphism, Premium Dark Mode)
- **Assets:** Official ZeroToCheckout branding and iconography.
- **Design Philosophy:** Inspired by Stripe, Vercel, and Linear.

## 📂 Project Structure
- `index.html`: **The Path** — Agitation, segments, and the masterclass promise.
- `curriculum.html`: **The Transition** — Technical breakdown of the 48-hour launch.
- `why-us.html`: **The Mission** — Ending the technical hostage crisis.
- `join-cohort.html`: **The Enrollment** — Architectural tiers (Student, Professional, Strategic Founder).
- `contact.html`: **The Inquiry** — Enrollment and technical support.
- `css/`: Modular CSS (Variables, Base, Components, Layouts).
- `assets/`: Official brand assets and logo.

## 🏗️ Getting Started
1. Clone the repository.
2. Open `index.html` in any modern browser.
3. No build step required (Vanilla implementation for maximum portability and speed).
